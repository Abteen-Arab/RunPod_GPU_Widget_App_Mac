RUNPOD DESKTOP

Build and install:
    bash RunpodDesktop/build.sh

Open ~/Applications/Runpod Desktop.app. The dashboard shows estimated
credit time, balance, hourly spend, and pod metrics. Use All / Running to
filter the pod list. The layout supports light and dark mode.

CONNECT

Create a read-only API key in Runpod Console > Credentials. Paste it into
the app and click Connect Runpod. The key is saved in macOS Keychain.
Enter it in the app, never in chat. The app only reads monitoring data;
it cannot start, stop, or delete pods.

DESKTOP WIDGET

Right-click your desktop > Edit Widgets > search Runpod Desktop.
Choose a small, medium, or large widget. The medium size shows two pods;
the large size shows up to six. The app's Desktop widget button shows
setup instructions, the placement count, and a refresh action.

Remove and re-add any OLD blank Runpod widget. Some previous builds used
a retired extension ID (ending in .MonitorWidget); those placements cannot
load the current extension (ending in .Widget).

If the widget is missing or blank, run from this repository:
    python3 RunpodDesktop/widget-doctor.py --repair --restart-host
Then open the installed app again and add a fresh widget.

The build and repair commands register one installed Runpod copy and
unregister old copies with the exact same app ID. They leave backup files,
widget placements, preferences, and credentials intact. The repaired widget
uses the macOS XPC extension entry point, so it stays available to its host.

UPDATES AND ESTIMATES

Keep the app running; closing its window is fine. Open it again after
restarting your Mac. It checks Runpod once per minute. The widget requests
updates every 15 minutes, and macOS decides when it actually redraws.
Clicking the widget opens the app and requests a refresh.

Last-known readings remain visible during startup and connection failures.
Readings older than 15 minutes are marked stale. Disconnect removes the
saved key and clears the widget snapshot. Sample data stays in the app;
it is never sent to your desktop widget.

Credit time is account balance divided by current hourly spend, rounded
down. It assumes constant spending, and is not a billing guarantee.
Zero reported spend shows No spend. Missing values show a dash. Pod status
does not check whether the application running inside the pod is healthy.

The widget receives a sanitized snapshot over an authenticated loopback
connection, never the Runpod API key.

CHECKS AND PREVIEWS

    bash RunpodDesktop/check.sh
    bash RunpodDesktop/render-previews.sh

Checks cover API parsing, metrics, estimates, authentication, widget cache,
startup loading/failure, disconnect, and offline fallback, using isolated
local test data. Previews are rendered from the actual views with sample
data only, into .build/previews. RunpodWidgetPreview.png is the main figure.

Requires an Apple silicon Mac, macOS 14 or later, and Apple's Command Line
Tools. The build is locally ad hoc signed, not notarized or an App Store
release. See README.md for architecture and further troubleshooting.
